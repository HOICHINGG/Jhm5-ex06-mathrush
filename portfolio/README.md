# Portfolio Website

A clean, minimalist portfolio website showcasing my projects.

## Features
- Grey background with white square cards
- Responsive grid layout
- Links to live projects
- Clean, modern design

## Projects Included
- **Math Rush Challenge** - Interactive math game built with React
  - Live at: https://mathgame-react.hoichingg.workers.dev/

## Tech Stack
- HTML5
- CSS3 (Grid Layout, Flexbox)
- Cloudflare Workers for hosting

## Deployment
To deploy to Cloudflare Workers:
```bash
npx wrangler deploy
```

## Design
- Background: Grey (#6b7280)
- Cards: White with square corners (border-radius: 0)
- Clean, professional aesthetic
- Hover animations and transitions
